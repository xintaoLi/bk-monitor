# AAFE Project Skill Entry (Cursor / web)

This file is a thin pointer for AIBOT / Cursor discovery.

Read `bklog/web/.ai-agent/skill-index.md` first, then `bklog/web/.ai-agent/project.md` if present, and only then load the matching `bklog/web/.ai-agent/project-skills/<domain>/SKILL.md` on demand.

`.ai-agent` SKILL.md files are not a second skill source. Trigger them through `.cursor/skills/<name>/SKILL.md`.

Do not copy project knowledge into this editor directory. The single source of truth is the module `.ai-agent` directory.
